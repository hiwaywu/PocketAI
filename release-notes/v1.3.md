Replies keep running in the background, and NT Media billing.

**Replies no longer stop when you leave the app**
- A quiet "Pocket AI is replying…" notification keeps the app alive and online until the answer is finished, even with the screen off.
- Swiping the app away or reopening it doesn't cancel or lose a reply.
- A "Reply ready" notification appears when an answer finishes while you're in another app; tap it to open that chat.
- Switching chats no longer stops a reply; each chat replies on its own (spinner in the chat list).
- Dropped connections (Wi-Fi ↔ mobile data, provider hiccups) are retried automatically.

**NT Media billing**
- Each reply shows raw and billed tokens (e.g. `1.2k tokens ×3.5 = 4.2k`) using NT Media's per-model multipliers; the usage screen, chat header and model menu use billed numbers.
- NT Media and OpenCode Go added to the API address shortcuts. OpenCode Go now works: Pocket AI sends the per-chat `x-opencode-session` header it requires (fixes "Request is missing x-opencode-session").

**Install note (one time only):** 1.3 is signed with a new permanent key, so Android can't install it over 1.2. Uninstall 1.2 first, then install 1.3 and re-enter your API (chats from 1.2 are removed). From 1.3 on, every update installs over the previous one and keeps your chats.

The in-app browser now runs on Firefox's engine (GeckoView), with uBlock Origin built in.

**Firefox engine + add-ons**
- The Browser tab uses the same engine as Firefox for Android, so it runs Firefox add-ons.
- **uBlock Origin** is installed automatically from addons.mozilla.org the first time you open the browser, and keeps itself updated. It blocks ads and handles "you're using an ad blocker" walls far better than the old built-in blocker, which is gone.
- ⋮ → **Add-ons**: turn add-ons on/off, open their settings (e.g. uBlock Origin's dashboard), remove them, or add more by pasting an addons.mozilla.org link or typing a name (e.g. "dark reader").
- ⋮ → **Block ads (uBlock Origin)** turns uBlock Origin on/off.

**Still there**
- Tabs, bookmarks, find in page, share, copy link, open in another browser, desktop site, text size, Unblock page, and the message bar that sends your question with the page (article-only on article pages).
- New: long-press a link for Open in new tab / Copy link / Share; links that open a new window open as a tab; page drop-down lists, alerts and confirm boxes use proper dialogs.

**Size:** the app is now ~100 MB (Firefox's engine), and only for 64-bit ARM phones like the Galaxy Z Fold 7.

Installs over 1.4–1.13 and keeps your chats. Your browser tabs and bookmarks carry over; sites will ask you to sign in again (new engine, new cookies).

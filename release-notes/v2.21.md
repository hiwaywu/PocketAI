The menu that appears when you select text in a chat now starts with **Web search**.

- **Web search:** select a word or sentence in a reply (or in the button panel) and tap **Web search**: Pocket AI
  searches it in the same chat, so the answer uses what you were talking about.
- The menu no longer shows **Save to Samsung Pass**, or **Ask Pocket AI** (that one is for other apps). Copy, Select
  all, Translate and Read aloud stay.

Installs over 2.2–2.20 and keeps your chats.
